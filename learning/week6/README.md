# Week 6 - RAG 收口 + 金融机构接入 Skill 设计

## 本周目标

完成 Week 5 的延迟复习和 RAG 工程闭环，冻结作品集一的业务边界、标准领域模型、数据政策、评估集与 V1 验收线。

## 通过标准

- 能独立解释 `retrieved_candidates → accepted_evidence → raw_output → final_output`；
- Skill 项目不依赖前公司代码、内部文档或真实字段；
- 每个 V1 功能均有测试或评估证据，Agent 不绕过人工确认。
