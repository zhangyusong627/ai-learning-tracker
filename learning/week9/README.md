# Week 9 - 投递反馈 + Java/AI 面试强化

## 本周目标

第二个作品集已提前完成，本周不再扩展新功能。围绕首批投递反馈，强化 Java 基础、RAG 与 Agent 项目表达，并建立持续投递闭环。

## 课程安排

| 日期 | 时间 | 主题 | 必须产出 |
|---|---:|---|---|
| 8.17 周一 | 7h | 投递漏斗与反馈分类 | 岗位、匹配度、反馈阶段和主要缺口记录 |
| 8.18 周二 | 7h | Java、JVM 与并发口述 | 高频题口述、追问与参考答案复盘 |
| 8.19 周三 | 7h | Spring、数据库与中间件 | Spring、事务、MySQL、Redis、消息队列场景题 |
| 8.20 周四 | 7h | RAG 作品集深挖 | 切块、混合检索、证据准入、评测指标和失败案例 |
| 8.21 周五 | 7h | Agent 作品集深挖 | 状态流、工具边界、确定性闸门、人工审批与安全评估 |
| 8.22 周六 | 4h | 综合模拟面试 | 围绕真实岗位连续追问，形成缺口清单 |
| 8.23 周日 | 4h | 定向补投与周复盘 | 只修正真实反馈暴露的问题并补投高匹配岗位 |

## 通过标准

- 所有项目数字和经历都能说明来源、口径与本人贡献；
- 能独立完成 Java、RAG、Agent 三类核心问题的 3 分钟回答；
- 每次模拟或真实面试都形成可执行的缺口清单；
- 不因继续做作品集功能而推迟投递。
