# Week 9 - AI 智能守护 V0.1

## 本周目标

创建独立作品集二，用模拟指标、事件回放和专家规则建立无大模型也能运行的确定性治理基线。

## 课程安排

| 日期 | 时间 | 主题 | 必须产出 |
|---|---:|---|---|
| 8.17 周一 | 7h | 独立仓库 + 指标决策模型 | AGENTS、目录规范、机构/接口/容量模型 |
| 8.18 周二 | 7h | 模拟指标 + 事件回放 | 正常、突发流量、超时和错误率事件 |
| 8.19 周三 | 7h | 专家规则引擎 | 规则匹配、动作建议和确定性结果 |
| 8.20 周四 | 7h | 优先级、冲突、冷却与防抖 | 多规则命中、频繁调整和震荡处理 |
| 8.21 周五 | 7h | 安全校验 + 审计状态 | 指标、规则、建议、原因、版本和拒绝 |
| 8.22 周六 | 4h | 命令行或 API 演示 | 事件输入、规则判断、建议和审计 |
| 8.23 周日 | 4h | 确定性基线评估 | 测试、失败样例、架构讲解和项目问答 |

## 通过标准

- 不依赖真实生产指标或内部规则；
- 专家规则基线可以在无大模型时独立运行；
- 所有策略建议经过确定性校验并留有审计记录；
- 第二个项目保持独立仓库，不与机构接入 Skill 合并。
