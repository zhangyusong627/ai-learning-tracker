# Week 9 - AI 智能守护 V0.1

## 本周目标

用模拟指标和专家规则构建智能守护基线，先证明业务闭环、安全边界和审计能力，再引入大模型建议。

## 课程安排

| 日期 | 时间 | 主题 | 必须产出 |
|---|---:|---|---|
| 8.17 周一 | 7h | 指标与决策模型 | QPS、延迟、错误率、并发状态模型 |
| 8.18 周二 | 7h | Sentinel / Hippo4j 与安全边界 | 可调整项、不可调整项、硬限制 |
| 8.19 周三 | 7h | 指标模拟与历史回放 | 可复现时序样本和事件 |
| 8.20 周四 | 7h | 专家规则引擎 | 规则匹配、优先级、冲突处理 |
| 8.21 周五 | 7h | 策略校验与审计 | 原因、输入、输出、版本记录 |
| 8.22 周六 | 4h | 模拟控制面 V0.1 | 建议、审批、模拟执行链路 |
| 8.23 周日 | 4h | V0.1 复盘 + 项目面试 | 架构讲解和失败场景问答 |

## 通过标准

- 不依赖真实生产指标或内部规则；
- 专家规则基线可以在无大模型时独立运行；
- 所有策略建议经过确定性校验并留有审计记录。
