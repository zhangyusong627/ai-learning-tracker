# Week 8 - 金融机构接入 Skill V1

## 本周目标

把抽取、检索、差异判断、人工确认、生成和验证编排为可恢复工作流，形成可投递的第一个独立作品集。

## 课程安排

| 日期 | 时间 | 主题 | 必须产出 |
|---|---:|---|---|
| 8.10 周一 | 7h | Skill 结构与渐进式上下文 | 可复用 SKILL.md 与资源导航 |
| 8.11 周二 | 7h | Tool Calling + LangGraph | 状态、节点、失败分支 |
| 8.12 周三 | 7h | Human-in-the-loop | 低置信度暂停与确认 |
| 8.13 周四 | 7h | 配置 + Java 适配器骨架生成 | 经批准映射驱动的模板输出 |
| 8.14 周五 | 7h | Maven 编译 + 契约测试 | 生成物确定性校验 |
| 8.15 周六 | 4h | 端到端验收 + 评估 | V1 报告、Bad Case、边界 |
| 8.16 周日 | 4h | 作品集发布材料 + 面试 | README、架构图、Demo、项目问答 |

## 通过标准

- 未确认映射不能进入生成节点；
- 生成失败能够定位到输入、模板或验证环节；
- README 不夸大能力，清楚说明模拟数据和安全边界；
- 从本周起启动小批量高匹配岗位投递。
