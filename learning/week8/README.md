# Week 8 - Agent 最小闭环 + 首批投递

## 本周目标

在已经收尾的 RAG Demo 之上学习 Agent（智能体）的最小闭环：模型决策、工具调用、显式状态、失败恢复、人工确认和评估；同时于 8 月 12 日启动首批投递，不再等待第二个作品集完成。

## 课程安排

| 日期 | 时间 | 主题 | 必须产出 |
|---|---:|---|---|
| 8.10 周一 | 7h | Agent 与 Workflow + Tool Calling | 能判断何时需要 Agent，并跑通一次模型选择工具的最小实践 |
| 8.11 周二 | 7h | 显式状态 + 决策循环 + 错误恢复 | 状态图、终止条件、超时和工具失败路径 |
| 8.12 周三 | 7h | Human-in-the-loop（人工参与闭环）+ 首批投递 | 高风险动作审批闸门；第一批高匹配 Java + AI 岗位 |
| 8.13 周四 | 7h | 最小 Agent 实现 | 使用合成指标完成观察、分析、工具调用、建议和终止闭环 |
| 8.14 周五 | 7h | Agent 评估 + 审计 | 正常、工具失败、无证据、越权和人工拒绝测试 |
| 8.15 周六 | 4h | RAG + Agent 项目讲解 | 3 分钟口述、架构取舍和失败案例 |
| 8.16 周日 | 4h | 周复盘 + 定向投递 | 记录掌握证据、薄弱点和第二批投递 |

## 通过标准

- 能用自己的话区分 Agent 与固定 Workflow，并给出选型理由；
- 最小 Agent 的状态、工具输入输出、终止条件和失败路径均可复现；
- 高风险动作必须经过确定性规则和人工确认，模型不能直接执行；
- 至少有一组正常、工具失败、越权和人工拒绝评测；
- 8 月 12 日完成可投递简历并启动小批量高匹配岗位投递。
