## 一、Transformer 是什么？

**一句话**：一种基于 Attention 机制的神经网络架构，用于处理序列数据（如文本）。

### 所有大模型都基于它

| 模型 | 架构 |
|------|------|
| GPT-2/3/4 | Transformer（解码器） |
| BERT | Transformer（编码器） |
| DeepSeek | Transformer |
| 文心一言 | Transformer |

---

### Transformer 的功能

| 功能 | 说明 |
|------|------|
| **理解文本** | 输入文本，输出每个词的上下文表示 |
| **生成文本** | 根据上下文，逐个生成下一个词 |
| **并行计算** | 多个 Attention 同时计算，速度快 |

---

### 为什么能成为所有大模型的框架？

| 优势 | 说明 |
|------|------|
| **并行计算** | 所有词同时处理，训练快 |
| **语义理解** | Attention 关注相关词，理解上下文 |
| **不遗忘** | 直接关注所有词，不会遗忘早期信息 |
| **可扩展** | 层数可堆叠，从 12 层到 96 层 |

## 二、Attention 机制

### 核心思想

**找相关词 + 加权求和**

```
"我 喜欢 吃 苹果"
     ↓
对于"吃"这个词：
- "吃" 和 "我" 的相关性：0.1
- "吃" 和 "喜欢" 的相关性：0.2
- "吃" 和 "吃" 的相关性：0.1
- "吃" 和 "苹果" 的相关性：0.6
     ↓
加权求和：0.1×"我" + 0.2×"喜欢" + 0.1×"吃" + 0.6×"苹果"
     ↓
"吃" 的新向量（包含了上下文信息）
```

---

### Attention 的输入输出

| 项目 | 说明 |
|------|------|
| **输入** | 词的原始向量 |
| **输出** | 词的新向量（包含上下文信息） |
| **维度** | 不变（输入 4 维，输出还是 4 维） |

---

### 计算公式

```
Attention(Q, K, V) = softmax(QK^T / √d_k) × V
```

| 符号 | 含义 |
|------|------|
| Q | Query（查询）：我在找什么？ |
| K | Key（键）：我是什么？ |
| V | Value（值）：我的内容是什么？ |
| d_k | Key 的维度 |
| softmax | 归一化，让权重和为 1 |

---

## 三、Multi-Head Self-Attention（多头注意力）

### 什么是多头？

**一句话**：多个 Attention 并行计算，每个关注不同的关系。

---

### 为什么需要多头？

```
"我 喜欢 吃 苹果"
```

- 语法关系："吃" → "苹果"（动宾关系）
- 语义关系："喜欢" → "苹果"（情感关系）
- 位置关系："吃" → "我"（主语）

**一个 Attention 只能学到一种关系，多头可以同时学多种。**

---

### 怎么实现的？

```
输入：[0.1, 0.9, 0.3, 0.5]  （4 维）

分成 2 个头：

头 1：取前 2 维 [0.1, 0.9]
- 学习语法关系
- 输出 [0.3, 0.7]

头 2：取后 2 维 [0.3, 0.5]
- 学习语义关系
- 输出 [0.4, 0.6]

拼接：[0.3, 0.7, 0.4, 0.6]
线性变换：[0.35, 0.65, 0.45, 0.55]  （最终输出）
```

---

### 头数 vs 维度

| 概念 | 说明 |
|------|------|
| **维度** | 向量的长度（如 768、1024） |
| **头数** | 注意力头的数量（如 8、12、16） |

**头数是超参数，不是由维度决定的。**

常见配置：

| 模型 | 维度 | 头数 | 每个头的维度 |
|------|------|------|-------------|
| GPT-2 | 768 | 12 | 64 |
| GPT-3 | 12288 | 96 | 128 |
| BERT | 768 | 12 | 64 |

---

### 并行计算

```
传统方式（串行）：
头 1 计算完 → 头 2 计算完 → 头 3 计算完 → ...
总时间 = 头1 + 头2 + 头3

并行方式：
头 1、头 2、头 3 同时计算
总时间 = max(头1, 头2, 头3)
```

**多头可以同时计算，不需要等待，速度快。**

---

### 多头学什么是模型自己决定的

```
训练前：不知道每个头会学什么
训练后：观察发现头 1 可能学语法，头 2 可能学语义
```

**这是"黑盒"的特性，不是人设定的。**

## 四、位置编码（Positional Encoding）

### 为什么需要位置编码？

```
"我 吃 苹果" vs "苹果 吃 我"
```

如果只看 Self-Attention，两个句子的"吃"会得到相同的表示，但意思完全不同。

**解决**：加入位置编码，让模型知道每个词的位置。

---

### 位置编码怎么来的？

**公式**（简化）：

```
PE(pos, 2i) = sin(pos / 10000^(2i/d))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d))
```

| 符号 | 含义 |
|------|------|
| pos | 词的位置（0, 1, 2, ...） |
| i | 维度索引 |
| d | 向量维度 |

---

### 位置编码的维度

**位置编码维度 = 词向量维度**，因为要相加。

```
最终向量 = 词嵌入 + 位置编码

"吃" 的最终向量 = [0.1, 0.9, 0.3, ...] + [0.84, 0.54, 0.00, ...]
```

---

### 位置编码的特点

| 特点 | 说明 |
|------|------|
| **唯一性** | 每个位置的编码不同 |
| **相对性** | 两个位置的编码差值有规律 |
| **无参数** | 公式固定，不需要训练 |

---

## 五、Add & Layer Normalization

### Add = 残差连接（Residual Connection）

```
output = input + Attention(input)
```

**作用**：让信息可以直接跳过中间层，保留原始信息，防止梯度消失。

---

### Layer Normalization = 归一化

**归一化 = 把数据调整到标准分布**

```
归一化(x) = (x - mean) / std
```

**作用**：稳定训练过程，让每层的输出分布一致。

---

### 归一化 ≠ 激活函数

| 概念 | 作用 |
|------|------|
| **归一化** | 调整数值范围，稳定训练 |
| **激活函数** | 引入非线性，增强表达能力 |

---

## 六、Feed-Forward Network（前馈网络）

### 结构

```
输入 → 线性变换 → 激活函数 → 线性变换 → 输出
```

---

### 什么是线性变换？

```
输出 = W × 输入 + b
```

| 符号 | 含义 |
|------|------|
| W | 权重矩阵（可学习参数） |
| b | 偏置（可学习参数） |

---

### 什么是激活函数？

**激活函数 = 引入非线性**

```
没有激活函数：
线性变换1 → 线性变换2 = 一个大的线性变换
（多层没意义，相当于一层）

有激活函数：
线性变换1 → 非线性 → 线性变换2 = 非线性变换
（多层有意义，可以学复杂模式）
```

---

### 为什么是 2 层？

| 层数 | 效果 |
|------|------|
| 1 层 | 只有一次变换，表达能力有限 |
| 2 层 | 足够的表达能力，参数适中 |
| 3 层 | 表达能力更强，但参数多，容易过拟合 |

**2 层是经验值，平衡了表达能力和训练效率。**

```
│  │  编码器输出（每个词的上下文向量）                        │  │

│  │  │  6. Add & Layer Normalization                    │  │  │

│  │      ↓                                                │  │
│  │  Linear + Softmax → 预测下一个词                       │  │

│  └───────────────────────────────────────────────────────┘  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 八、编码器 vs 解码器

| 组件 | 作用 | GPT 用吗 |
|------|------|----------|
| **编码器** | 理解输入文本 | ❌ GPT 只用解码器 |
| **解码器** | 生成输出文本 | ✅ GPT 只用解码器 |

**GPT 是纯解码器模型**，只用 Decoder 部分。

---

## 九、每个组件的职能

| 组件 | 职能 |
|------|------|
| **Embedding** | 文本 → 向量 |
| **位置编码** | 加入位置信息 |
| **Self-Attention** | 找相关词 + 加权求和 |
| **多头注意力** | 多个 Attention 并行，关注不同关系 |
| **Add** | 残差连接，保留原始信息 |
| **Layer Norm** | 归一化，稳定训练 |
| **Feed-Forward** | 非线性变换，增强表达能力 |
| **Masked Attention** | 只关注前面的词，不能偷看未来 |
| **Cross-Attention** | 生成时参考编码器输出 |
| **Softmax** | 输出概率分布，选最高的词 |

## 十、深入讨论：Attention、Self-Attention、Multi-Head Self-Attention 的区别

### 三者关系

```
Attention（注意力机制）
    ↓ 特殊情况
Self-Attention（自注意力）
    ↓ 增强版
Multi-Head Self-Attention（多头自注意力）
```

---

### 详细对比

| 概念 | 关注什么 | 用途 |
|------|----------|------|
| **Attention** | 不同序列之间 | 翻译（中→英） |
| **Self-Attention** | 同一序列内部 | 理解上下文 |
| **Multi-Head Self-Attention** | 同一序列，多种关系 | 理解多种关系 |

---

### 例子

```
翻译任务：
"我 喜欢 吃 苹果" → "I like eating apples"

Attention：
- "I" 关注 "我"（中英文之间）
- "like" 关注 "喜欢"（中英文之间）

Self-Attention：
- "吃" 关注 "苹果"（中文内部）

Multi-Head Self-Attention：
- 头 1：关注语法（动宾关系）
- 头 2：关注语义（情感关系）
- 头 3：关注位置（前后关系）
```

---

## 十一、深入讨论：GPT 为什么不用编码器？

### 核心原因：任务不同

| 模型 | 任务 | 用什么 |
|------|------|--------|
| **GPT** | 生成文本 | 只用解码器 |
| **BERT** | 理解文本 | 只用编码器 |
| **T5** | 翻译、摘要 | 编码器 + 解码器 |

---

### GPT 的工作方式

```
输入："今天天气"
     ↓
解码器的 Self-Attention 理解上下文
     ↓
生成："真"
     ↓
生成："好"
     ↓
...
```

**GPT 把"理解"和"生成"合二为一了，不需要单独的编码器。**

---

### 编码器 vs 解码器的 Self-Attention

| 类型 | 能看到什么 | 用途 |
|------|-----------|------|
| **编码器的 Self-Attention** | 所有词（包括后面的） | 理解整句话 |
| **解码器的 Self-Attention** | 只能看自己和前面的词 | 生成文本 |

---

### 为什么现在翻译任务不需要编码器？

**不是技术进步替代了编码器，而是发现：通过 Self-Attention 和海量数据训练，纯解码器的理解能力已经足够好。**

| 时间 | 认知 | 数据/计算 |
|------|------|-----------|
| 2017 | 理解和生成是分开的 | 有限 |
| 2018 | 纯解码器也能理解 | 海量 |

---

## 十二、深入讨论：超参数

### 什么是超参数？

| 概念 | 说明 | 举例 |
|------|------|------|
| **参数** | 模型训练时自动学习的 | 权重 W、偏置 b |
| **超参数** | 人工设定，训练前就确定的 | 头数、层数、学习率 |

---

### Transformer 中的超参数

| 超参数 | 说明 | 举例 |
|--------|------|------|
| **头数** | 多头注意力有几个头 | 8、12、16 |
| **层数** | 编码器/解码器有几个 Block | 6、12、24 |
| **维度** | 向量的长度 | 768、1024、12288 |
| **学习率** | 每次更新参数的步长 | 0.001、0.0001 |

---

### 超参数怎么确定？

| 方式 | 说明 |
|------|------|
| **经验值** | 用前人总结的配置（常用） |
| **网格搜索** | 尝试所有组合，选最好的 |
| **随机搜索** | 随机尝试，比网格搜索快 |

**超参数靠经验或搜索确定，没有公式能算出最优。**

## 十三、核心思想总结

| 概念 | 一句话解释 |
|------|------------|
| **Transformer** | 基于 Attention 的并行架构，解决 RNN 的串行和遗忘问题 |
| **Attention** | 找相关词 + 加权求和 |
| **Self-Attention** | 同一序列内部的 Attention，每个词关注所有其他词 |
| **Multi-Head Self-Attention** | 多个 Self-Attention 并行，关注不同关系 |
| **多头** | 多个 Attention 并行，关注不同关系 |
| **位置编码** | 让 AI 知道词的顺序 |
| **残差连接** | 保留原始信息，防止梯度消失 |
| **Layer Norm** | 归一化，稳定训练 |
| **Feed-Forward** | 非线性变换，增强表达能力 |
| **超参数** | 人设定的训练规则，决定模型的形状和能力 |

## 十四、练习题

### 题目 1：Attention 机制

请用一句话解释 Attention 机制的核心思想。

**答案**：计算当前词与所有词的相关性，用相关性作为权重进行加权求和，得到当前词的新表示。

---

### 题目 2：多头注意力

为什么需要多头注意力？

**答案**：一个 Attention 只能学到一种关系，多头可以同时学多种关系（语法、语义、位置等）。

---

### 题目 3：位置编码

为什么需要位置编码？

**答案**：Self-Attention 只计算相关性，不关心位置。加入位置编码让模型知道词的顺序。

---

### 题目 4：残差连接

残差连接的作用是什么？

**答案**：让信息可以直接跳过中间层，保留原始信息，防止梯度消失。

---

### 题目 5：Transformer vs RNN

Transformer 比 RNN 好在哪里？

**答案**：
- 并行计算：所有词同时处理，速度快
- 长距离依赖：直接关注所有词，不会遗忘
- 语义理解：通过 Attention 理解上下文

---

### 题目 6：Attention vs Self-Attention

Attention 和 Self-Attention 的区别是什么？

**答案**：
- Attention：关注不同序列之间（如中英文）
- Self-Attention：关注同一序列内部（如中文内部）

---

### 题目 7：GPT 为什么不用编码器？

GPT 为什么不需要编码器？

**答案**：
- GPT 的任务是生成，不是理解
- 解码器通过 Self-Attention 也能理解上下文
- 通过海量数据训练，纯解码器的理解能力已经足够好

---

### 题目 8：超参数

什么是超参数？和参数有什么区别？

**答案**：
- 参数：模型训练时自动学习的（如权重 W）
- 超参数：人工设定的（如头数、层数）
- 超参数决定模型的形状，参数决定模型的能力

---

## 十五、学习心得

- Transformer 是所有大模型的基础架构
- Attention 的核心是"找相关词 + 加权求和"
- Self-Attention 是同一序列内部的 Attention
- Multi-Head Self-Attention 是多个 Self-Attention 并行
- 多头让模型能同时关注多种关系
- 位置编码让模型知道词的顺序
- 残差连接和 Layer Norm 保证训练稳定
- Feed-Forward 增强非线性表达能力
- GPT 不用编码器是因为任务是生成，不是理解
- 超参数是人设定的，决定模型的形状
- 理解核心思想即可，不需要深入数学公式
