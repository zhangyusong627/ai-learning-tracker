## 一、Token

### 什么是 Token？

**一句话**：Token 是大模型处理文本的最小单位。

**不是字，也不是词**，而是模型"看"文本的方式。

| 文本 | Token 划分 |
|------|-----------|
| "我喜欢编程" | ["我", "喜欢", "编程"] → 3 个 Token |
| "AI is great" | ["AI", " is", " great"] → 3 个 Token |
| "embedding" | ["embed", "ding"] → 2 个 Token |

---

### Token 划分规则

| 类型 | 示例 | Token 数 |
|------|------|----------|
| 中文 | "我喜欢编程" | 3-4 个 |
| 英文 | "Hello World" | 2 个 |
| 代码 | `print("hello")` | 4-5 个 |
| 空格 | "a b c" | 3 个 |

---

### 为什么 Token 重要？

| 原因 | 说明 |
|------|------|
| **计费** | API 按 Token 数收费 |
| **限制** | 模型有最大 Token 限制（如 4096、8192） |
| **性能** | Token 越多，处理越慢 |

---

### Token 限制

| 模型 | 最大 Token |
|------|-----------|
| GPT-3.5 | 4,096 |
| GPT-4 | 8,192 / 32,768 |
| DeepSeek Chat | 4,096 |
| DeepSeek Coder | 16,384 |

**超过限制会报错**：`Maximum context length exceeded`

## 二、Embedding

### 什么是 Embedding？

**官方定义**：将离散的变量（如单词、句子）映射到连续的向量空间中的过程或结果。

**通俗解释**：把文本转换成数字数组，让计算机可以理解和计算。

---

### 两种转换方式对比

| 方式 | "猫" | "狗" | "汽车" | 语义关系 |
|------|------|------|--------|----------|
| 简单编码 | 29575 | 29399 | 27773 | ❌ 没有 |
| Embedding | [0.2, 0.8, 0.1] | [0.3, 0.7, 0.2] | [0.9, 0.1, 0.8] | ✅ 保留 |

---

### Embedding 的核心价值

**不仅是转换，更重要的是保留语义关系**。

| 价值 | 说明 |
|------|------|
| **语义相似度** | 计算两个文本有多相似 |
| **搜索** | 找语义相近的内容 |
| **分类** | 把相似文本归为一类 |

---

## 三、语义向量

### 向量维度

每种 Embedding 模型的维度是固定的：

| 模型 | 维度 |
|------|------|
| text-embedding-3-small | 1,536 |
| text-embedding-3-large | 3,072 |
| DeepSeek Embedding | 1,024 |

---

### 余弦相似度

计算两个向量的相似程度：

```python
import numpy as np

def cosine_similarity(a, b):
    return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))

# 向量
cat = [0.2, 0.8, 0.1, 0.5]
dog = [0.3, 0.7, 0.2, 0.4]
car = [0.9, 0.1, 0.8, 0.2]

print(f"猫 vs 狗: {cosine_similarity(cat, dog):.2f}")  # 0.97
print(f"猫 vs 汽车: {cosine_similarity(cat, car):.2f}")  # 0.24
```

| 对比 | 相似度 | 含义 |
|------|--------|------|
| 猫 vs 狗 | 0.97 | 很相似（都是宠物） |
| 猫 vs 汽车 | 0.24 | 不相似 |

---

### 向量运算发现语义关系

```
king（国王） - man（男人） + woman（女人） ≈ queen（女王）
```

**这说明**：Embedding 不仅是编码，还**学到了语义关系**。

## 四、Embedding 原理

### 训练过程：猜词游戏

```
1. 收集大量文本（书籍、网页、对话）
2. 让模型玩猜词游戏
3. 模型不断调整参数
4. 得到一个训练好的 Embedding 模型
```

**这一步是离线的，由 OpenAI/DeepSeek 等公司完成。**

---

### 每个维度的值怎么算出来的？

每个维度代表模型学到的某种**特征**。

| 维度 | 可能代表的含义 |
|------|----------------|
| 维度 1 | 动物程度 |
| 维度 2 | 体型大小 |
| 维度 3 | 情感倾向 |
| ... | ... |

**注意**：这些维度的含义是**隐式的**，模型没有明确告诉你每个维度代表什么，只是通过训练自然形成的。

## 五、Token vs Embedding vs 向量

| 概念 | 输入 | 输出 | 说明 |
|------|------|------|------|
| **Token** | 文本 | Token 列表 | 分词 |
| **Embedding** | 文本（或 Token） | 向量 | 语义编码 |
| **向量** | - | 数字数组 | Embedding 的输出 |

## 七、练习题

### 题目 1：Token

请解释什么是 Token，为什么大模型需要 Token？

**答案**：
- Token 是大模型处理文本的最小单位
- 计算机不懂文字，只懂数字
- Token 是文本到数字的中间步骤
- API 按 Token 数收费
- 模型有 Token 数量限制

---

### 题目 2：Embedding

Embedding 和简单编码有什么区别？

**答案**：
- 简单编码：只是把字符映射到数字，没有语义关系
- Embedding：通过大量文本训练，保留了语义关系
- 语义相似的文本，Embedding 向量也相似
- 可以通过向量计算相似度

---

### 题目 3：语义相似度

```
"猫"   → [0.2, 0.8, 0.1, 0.5]
"狗"   → [0.3, 0.7, 0.2, 0.4]
"汽车" → [0.9, 0.1, 0.8, 0.2]
```

**问题**：哪个和"猫"最相似？为什么？

**答案**：狗。因为向量更接近，余弦相似度更高（0.97 vs 0.24），说明语义更相似。

## 八、学习心得

- Token 是大模型处理文本的最小单位，不是字也不是词
- Embedding 不仅是转换，更重要的是保留语义关系
- 每个维度代表模型学到的某种特征
- 通过训练，语义相似的词在向量空间中距离更近
- 可以通过向量运算发现语义关系（如 king - man + woman ≈ queen）
