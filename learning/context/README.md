# Context Handoff

本目录保存跨工具协作所需的脱敏上下文材料，用于让 Claude Code、Codex 或其他本地 AI 编程工具快速理解当前学习项目状态。

## 规则

- 只放经过整理和脱敏的上下文摘要，不放原始聊天记录。
- 不复制公司内部文档、截图、接口字段、密钥、URL、IP、测试数据或专有代码。
- 文件内容应服务于继续工作：项目背景、当前进度、已确认决策、待办事项、约束和下一步。
- 当课程计划、作品集方向或关键决策发生变化时，更新对应上下文文件。

## 当前交接入口

- [codex-to-claude-context.md](codex-to-claude-context.md)：当前脱敏项目上下文，跨工具接手时优先读取。
- 针对某次工具切换生成的临时交接文件只保存在本机，不纳入 Git；长期有效信息必须合并进本文件或 `learning/PROGRESS.md`。
