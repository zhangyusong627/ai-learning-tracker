# Week 10 - AI 智能守护 V1

## 本周目标

在确定性基线上增加治理知识检索和策略建议 Agent。模型只分析与建议，硬规则和人工审批掌握最终控制权。

## 课程安排

| 日期 | 时间 | 主题 | 必须产出 |
|---|---:|---|---|
| 8.24 周一 | 7h | Agent 边界 + 状态流 | 观察、分析、建议、校验、审批、模拟执行和终止 |
| 8.25 周二 | 7h | 指标、规则与历史事件工具 | 只读工具、参数校验、错误返回和审计 |
| 8.26 周三 | 7h | 专家经验 RAG 知识库 | 规则、案例和边界的可追溯证据 |
| 8.27 周四 | 7h | 分析 → 建议 → 解释 Agent | 建议、原因、证据、风险和待确认项 |
| 8.28 周五 | 7h | 硬闸门 + 人工审批 + 回滚 | 拒绝超限建议、批准合法建议、模拟回滚 |
| 8.29 周六 | 4h | 事件回放 + 对比评估 | 规则基线与 Agent 建议对比 |
| 8.30 周日 | 4h | V1 文档、演示与发布 | README、架构图、演示、评估报告和局限 |

## 通过标准

- 大模型只能生成建议，不能直接修改任何真实运行参数；
- 硬性安全规则优先于模型建议；
- 能演示正常、拒绝、超限和回滚四类路径；
- 形成可复现的评估报告和已知局限。
