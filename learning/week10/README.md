# Week 10 - 系统设计 + 项目深挖

## 本周目标

用真实投递和面试反馈强化 Java 系统设计、资金网关治理、RAG 与 Agent 工程取舍；真实面试优先，不横向扩展新技术。

## 课程安排

| 日期 | 时间 | 主题 | 必须产出 |
|---|---:|---|---|
| 8.24 周一 | 7h | 真实反馈分类与优先级 | 按知识、代码、项目证据、表达和岗位匹配分类 |
| 8.25 周二 | 7h | 资金网关系统设计 | 机构接入、事件流、幂等、补偿和隔离设计 |
| 8.26 周三 | 7h | 高并发与稳定性治理 | 限流、熔断、线程池、积压和降级场景题 |
| 8.27 周四 | 7h | AI 应用系统设计 | RAG 与 Agent 选型、状态、评估、安全和成本设计 |
| 8.28 周五 | 7h | 编码题与故障诊断 | 限时编码和线上问题定位记录 |
| 8.29 周六 | 4h | 目标岗位模拟面试 | 按真实 JD 进行系统设计和项目压力追问 |
| 8.30 周日 | 4h | 材料修正与定向投递 | 只修正真实反馈暴露的问题并继续投递 |

## 通过标准

- 能从业务目标、约束、数据流、故障路径和取舍完成系统设计；
- 项目回答严格区分本人真实工作、合成作品集和未来设想；
- 每个薄弱点都有新题或新场景验证，不能以“看过答案”代替掌握；
- 保持投递与面试节奏，不因学习计划延误真实机会。
