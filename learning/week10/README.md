# Week 10 - AI 智能守护 V1

## 本周目标

在专家规则基线上增加治理知识库和策略建议 Agent，完成安全闸门、人工审批、灰度观测、回滚与评估。

## 课程安排

| 日期 | 时间 | 主题 | 必须产出 |
|---|---:|---|---|
| 8.24 周一 | 7h | 治理 RAG 知识库 | 规则、案例、边界的可追溯检索 |
| 8.25 周二 | 7h | 策略建议 Agent / LangGraph | 建议、依据与状态流 |
| 8.26 周三 | 7h | 硬性安全闸门 | 最大幅度、冷却、审批限制 |
| 8.27 周四 | 7h | 模拟执行 + Human-in-the-loop | 暂停、批准、拒绝和恢复 |
| 8.28 周五 | 7h | 灰度、观测与回滚 | 回滚条件和演练记录 |
| 8.29 周六 | 4h | 评估集与 Bad Case | 风险建议、规则冲突、无证据场景 |
| 8.30 周日 | 4h | 文档、演示与面试 | V1 README、架构图、Demo、项目题库 |

## 通过标准

- 大模型只能生成建议，不能直接修改任何真实运行参数；
- 硬性安全规则优先于模型建议；
- 能演示正常、拒绝、超限、回滚四类路径；
- 形成可复现的评估报告和已知局限。
