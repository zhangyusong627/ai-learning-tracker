## 作品集一：金融机构接入 RAG Demo

仓库：`financial-institution-integration-skill`，已推送提交 `a88d943`。

- 链路：PDF / DOCX / XLSX / Markdown 解析 → 多粒度切块 → Embedding → Chroma → metadata 过滤 → 向量 + BM25 召回 → RRF 融合 → 证据准入 → 结构化抽取 → 人工闸门 → 评测与追溯。
- 评测：15 条黄金集上 Hit@5 / Recall@5 为 100%，可采纳证据召回率 91.67%，无答案拒答率 100%，Precision@5 为 25%。该集合参与过调试，不能当作独立泛化证明。
- 生成边界：只证明已知合成范例的 Java 方法体生成、编译、契约和证据追溯；不证明能从零生成全新机构完整 SPI 工程。
- 后续项：独立保留集、OCR 与通用 SPI 生成仅列为未来迭代，不再阻塞当前求职。
