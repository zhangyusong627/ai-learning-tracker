# Week 7 - 金融机构接入 Skill：三模式 LLM 直写闭环

## 本周目标

在 Week 6 的最小解析闭环上完成字段映射、差异识别、检索证据、人工确认、三模式完整 Java SPI 生成和确定性验证。

## 课程安排

| 日期 | 时间 | 主题 | 必须产出 |
|---|---:|---|---|
| 8.3 周一 | 7h | 标准字段映射 | 来源字段、转换规则、证据和状态 |
| 8.4 周二 | 7h | 差异、冲突与待确认项 | 缺失、枚举、流程、版本冲突处理 |
| 8.5 周三 | 7h | 带范围过滤的 RAG 证据检索 | 机构、产品、版本、权限过滤与证据定位 |
| 8.6 周四 | 7h | 证据编号 + 人工确认状态流 | 合法引用、批准、拒绝和恢复 |
| 8.7 周五 | 7h | LLM 直写完整 Java SPI | approved `code_model` + 检索证据 + 合成范式驱动生成 |
| 8.8 周六 | 4h | Maven 编译 + 契约测试 | 输入、模板、编译和契约失败定位 |
| 8.9 周日 | 4h | V0.1 集成 + 黄金集评估 | 正常、缺失、冲突和拒绝样例 |

## 通过标准

- 每个关键映射均有证据或明确标为待确认；
- 机构、产品、版本和权限条件在 Top-K 检索前生效；
- 未批准映射禁止生成 Java；
- 每个生成方法绑定 Evidence、Mapping、稳定 chunk ID 和文档定位，并通过追溯校验；
- Java 生成物通过编译和契约测试；
- 不能用模型“看起来合理”的回答代替黄金集评估。
