# Week 7 - 金融机构接入 Skill V0.1

## 本周目标

把公开或自造的 PDF、Word、Excel 接入资料转换为可追溯的标准模型、字段映射和差异报告。

## 课程安排

| 日期 | 时间 | 主题 | 必须产出 |
|---|---:|---|---|
| 8.3 周一 | 7h | 多格式统一解析 | 文档块统一模型与解析测试 |
| 8.4 周二 | 7h | Structured Output + JSON Schema | 可校验抽取结果 |
| 8.5 周三 | 7h | 标准领域模型 + RAG 索引 | 检索链路与证据定位 |
| 8.6 周四 | 7h | 元数据、版本与引用 | 来源、页码/工作表、版本字段 |
| 8.7 周五 | 7h | 字段映射与差异识别 | 映射表、缺失项、待确认项 |
| 8.8 周六 | 4h | 评估集与 V0.1 集成 | 黄金集、指标、Bad Case |
| 8.9 周日 | 4h | README、演示与首次投递准备 | 演示脚本、项目讲法、简历条目 |

## 通过标准

- 三种格式均可进入统一解析模型；
- 结构化输出可以被确定性 Schema 校验；
- 每个关键映射均有证据或明确标为待确认；
- 不能用模型“看起来合理”的回答代替黄金集评估。
