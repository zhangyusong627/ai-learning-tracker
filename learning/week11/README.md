# Week 11 - Java + AI 面试冲刺

## 本周目标

在 7 月 28 日起每日面试训练的基础上进行集中冲刺。真实面试优先于课程，不再扩展作品集功能。

## 课程安排

| 日期 | 时间 | 主题 | 必须产出 |
|---|---:|---|---|
| 8.31 周一 | 7h | 简历反馈 + 两个项目叙事 | 自我介绍、3 分钟和 10 分钟讲法 |
| 9.1 周二 | 7h | Java 核心、JVM 与并发 | 新口述题、手写题、线程池和诊断 |
| 9.2 周三 | 7h | Spring、事务与数据中间件 | MySQL、Redis、消息队列场景题 |
| 9.3 周四 | 7h | 资金网关 + AI 系统设计 | 机构接入、稳定性治理和作品集白板设计 |
| 9.4 周五 | 7h | RAG、Agent、评估与安全 | AI 应用工程深挖和失败路径追问 |
| 9.5 周六 | 4h | 编码题 + 综合模拟面试 | 限时完成、录音评分、缺口清单 |
| 9.6 周日 | 4h | 简历、作品集与投递漏斗修正 | 只修正真实反馈暴露的问题 |

## 通过标准

- 能在 3 分钟、10 分钟两个版本讲清每个项目；
- 能明确区分真实工作经验、个人作品集和未来设想；
- 所有高频问题至少经过一次闭卷口述或新题诊断；
- 面试反馈在 24 小时内转化为补强任务。
