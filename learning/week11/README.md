# Week 11 - Java + AI 面试冲刺

## 本周目标

把既有 Java 能力、资金网关业务经验和两个 AI 作品集组织为稳定、可追问、可验证的面试表达。

## 课程安排

| 日期 | 时间 | 主题 | 必须产出 |
|---|---:|---|---|
| 8.31 周一 | 7h | Java 核心、JVM、并发 | 口述题 + 手写/诊断题 |
| 9.1 周二 | 7h | Spring、MySQL、Redis、MQ | 场景题与系统取舍 |
| 9.2 周三 | 7h | RAG、Skill 与评估 | 作品集深挖题 |
| 9.3 周四 | 7h | Agent、智能守护与系统设计 | 白板架构与安全边界 |
| 9.4 周五 | 7h | 算法、编码与故障定位 | 限时编码和复盘 |
| 9.5 周六 | 4h | Java + AI 综合模拟面试 | 录音、评分、缺口清单 |
| 9.6 周日 | 4h | 简历、GitHub 与投递漏斗复盘 | 调整项目讲法和岗位策略 |

## 通过标准

- 能在 3 分钟、10 分钟两个版本讲清每个项目；
- 能明确区分真实工作经验、个人作品集和未来设想；
- 所有高频问题至少经过一次闭卷口述或新题诊断；
- 面试反馈在 24 小时内转化为补强任务。
