# 求职材料目录约定

本目录只保存经过事实核验、适合进入版本库的求职方法、清洗规则和公开版材料。原始简历、个人联系方式、薪资、身份证明、私人评估报告和未经确认的经历数据只保存在本机，不进入 Git。

## 内容边界

- 可提交：脱敏后的简历结构规则、面试复盘模板、投递记录模板、事实核验清单。
- 不提交：原始 PDF / Word 简历、私人交接、聊天记录、联系方式、薪资、个人证件、未确认数字和模型生成的私人评估报告。
- 简历与面试答案中的事实分为三类：本人真实工作经历、合成作品集证据、未来设想。三类不得混写。
- 所有业绩数字必须能说明统计口径、时间范围、本人贡献和可披露边界；不能说明的数字删除。
- 面试题答案不得杜撰“真实项目案例”。没有亲身案例时，应明确回答通用工程方案或合成 Demo 经验。

- 正式提交简历前，先完成学历、技术栈、项目数字、本人职责和可披露范围五项核验。
